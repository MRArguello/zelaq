# Link

An anchor — a real `<a href>` on web, a pressable `Text` on native that opens `href` via
`Linking.openURL`. Use it for actual navigation; use `Button` for actions that aren't a URL.

## Tokens

- `colors.primary` — text color
- `typography.body` — font family, size, weight, line-height

`onPress` is additive, not a replacement — it fires alongside navigation, the same way a real
anchor's `onClick` doesn't prevent following `href` unless you call `preventDefault`.
