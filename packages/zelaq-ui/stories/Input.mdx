# Input

A theme-aware text field for single-line user input. Pair it with `Text`-rendered labels and
helper/error copy rather than styling your own.

<Canvas of={InputStories.Default} />

<Controls of={InputStories.Default} />

## Tokens

- `colors.fieldBackground` — default: background
- `colors.fieldDisabledBackground` — disabled: background
- `colors.secondaryBorder` — default: border
- `colors.borderFocused` — focused: border
- `colors.textDanger` — error: border, message color
- `colors.textDefault` — default: text
- `colors.fieldDisabledText` — disabled: text
- `colors.textMuted` — placeholder
- `radii.xs` — corner radius
- `space.base` — horizontal padding
- `space['2md']` — vertical padding
- `space.sm` — gap (label / field / helper)

Disabled state uses its own dedicated tokens rather than dimming the normal ones via opacity —
opacity alone wasn't distinct enough between default and disabled.

## Helper and error text

`errorMessage` takes priority over `helperText` when both are present, and switches the border and
message color to `textDanger`.

## Controlled value

`value`/`onChangeText` work like any other controlled input — `onChangeText` receives the plain
string value on both platforms (React Native's own native API; web's `onChange` event is adapted
to match it internally).

## Platform notes

Web can't theme the `::placeholder` pseudo-element through inline styles (this library has no
stylesheet/CSS-in-JS layer), so placeholder text uses the browser's native styling. Native uses
`placeholderTextColor` from `colors.textMuted` directly, since `TextInput` exposes it as a real
prop.
