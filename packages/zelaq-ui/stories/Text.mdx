# Text

A theme-aware text primitive for all typography in the library — headings, body copy, hero text.
Prefer it over raw platform text elements so type and color always stay theme-driven.

## Tokens

- `typography.<variant>` — from `variant` prop: font family, size, weight, line-height
- `colors.textDefault` — `tone="default"`: text color
- `colors.textMuted` — `tone="muted"`: text color
- `colors.textInverse` — `tone="inverse"`: text color
- `colors.textDanger` — `tone="danger"`: text color
- `colors.textSuccess` — `tone="success"`: text color

## Heading levels

Variants map to a default element: `heading1`–`heading4` render `<h1>`–`<h4>`, `subheading`
renders `<h2>`, `hero1`–`hero4` render `<h1>`, and body variants render `<p>`/`<span>`. Override
with `as` for real document structure independent of the visual styling — `as="h1"` for a page
title, `as="h3"` for a nested subsection. `as` accepts `h1`–`h6`/`p`/`span` and is web-only; native
always renders RN's `Text`, which has no element/semantic-level concept.
